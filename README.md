# Ayush Subramanian Portfolio

Static personal portfolio recreated from the previous Next.js version. It is ready to publish with GitHub Pages by placing these files at the root of `ayushsubramanian.github.io`.

## Files

- `index.html` contains the page content and links.
- `styles.css` contains the full responsive design.
- `script.js` controls the mobile navigation menu.
- `assets/` contains the local portfolio images copied from the original site.

## Edit

Update text directly in `index.html`. Project images can be replaced by dropping new files into `assets/` and updating the matching `src` path.
