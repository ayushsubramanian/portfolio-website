# Ayush Subramanian's Portfolio

A responsive personal portfolio website for Ayush Subramanian, built with HTML, CSS, and JavaScript. The site highlights my background, technical skills, projects, and professional interests across data analytics, business intelligence, and machine learning.

## Live Site

The portfolio is deployed on Vercel and can be viewed here:

```text
https://ayushsubramanian.vercel.app/
```

## Overview

This portfolio is designed to present my experience, skills, and projects in a clean and accessible format. It includes sections for my background, technical abilities, featured work, and ways to connect with me.

The site is fully responsive, making it easy to view across desktop, tablet, and mobile devices.

## Project Structure

```text
.
├── index.html
├── styles.css
├── script.js
└── assets/
```

## Files

### `index.html`

Contains the main website content, including page sections, navigation links, project descriptions, and portfolio text.

### `styles.css`

Contains the full responsive design, including layout, colors, typography, spacing, media queries, and visual styling.

### `script.js`

Controls basic interactive behavior, including the mobile navigation menu.

### `assets/`

Stores local images and visual assets used throughout the portfolio, including project images and personal branding elements.

## Editing the Site

To update the portfolio content, edit the text directly in `index.html`.

To replace project images or other visuals:

1. Add the new image file to the `assets/` folder.
2. Update the matching `src` path in `index.html`.
3. Save and refresh the page to view the changes.

## Running Locally

Because this is a static website, no build process is required. To preview the site locally, open `index.html` directly in a browser.

For a smoother local development experience, you can also use the Live Server extension in VS Code.
